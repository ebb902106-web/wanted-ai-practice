# Recovery Icon Image Prompts

These prompts are for replacing the temporary SVG placeholders in `public/recovery-icons/` with generated images.

## Shared Style

```text
Create a brand-new premium three-dimensional pixel-art icon representing {{subject}}. The icon should be made from exactly two material layers: a frosted smoked-black glass frame and opaque saturated colored plastic fills.

Use a casual saturated palette: bright teal, coral pink, sunny yellow, cobalt blue, fresh mint, and warm orange. The rear layer is one continuous frosted smoked-black glass plate in #151C24, forming the outer pixel silhouette and all internal pixel boundaries. The front layer contains opaque molded-plastic color fills at one consistent shallow raised height.

All pixel edges must be crisp, square, and planar. The icon should feel like a compact collectible object with visible glass thickness, satin-matte smoked edges, soft internal color diffusion, subtle contact shadows, and clean studio reflections.

Use premium studio product lighting. Place the centered isolated icon on a smooth seamless studio background in #CFE7F5. Show it slightly floating in a close dynamic three-quarter view from slightly above.

Constraints: no text, no watermark, no extra decorative objects, no flat vector style, no rounded blob shapes, exactly two material layers.
```
